# NADII — Cat Dungeon Survivors

Game survival 2D bergaya 2-bit pixel art yang berjalan langsung di browser dan GitHub Pages.

## Fitur saat ini
- Kustomisasi kucing: warna bulu, pakaian, topi, ekor, dan senjata.
- Dungeon gelap procedural dengan arena luas dan kamera mengikuti pemain.
- Kontrol gerak WASD / tombol panah; tersedia D-pad untuk layar sentuh.
- Auto attack dengan Sword, Bow, Staff, dan Throwing Knives.
- Musuh: Dog, Crow, Bat, Wolf, dan Boar.
- EXP orb, level-up, dan pilihan upgrade aktif/pasif.
- Boss setiap 10 fase.
- Progress kustomisasi disimpan di localStorage.

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages dari Settings → Pages → Deploy from a branch → main → /(root).

## Kontrol
- Gerak: WASD atau Arrow Keys
- Pause: Escape atau tombol II
- Serangan dan pemilihan target: otomatis

## Catatan
Versi ini merupakan fondasi playable pertama. Sprite musuh dan lingkungan digambar secara procedural di Canvas menggunakan palet terbatas; konten, balancing, animasi, dan variasi dungeon dapat dikembangkan bertahap.
